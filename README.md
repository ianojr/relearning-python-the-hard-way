# Relearning Python The Hard Way 🐍

> *"First, solve the problem. Then, write the code."*

## What This Is

This is not another tutorial repo. This is a **deliberate, from-scratch relearning journey** — every line of code written by hand, from memory, without AI generating it for me.

No copy-pasting. No following along. Just reading, understanding, closing the material, and writing it myself.

This is how real skills are built.

**Ian Rugi** — A Systems Software Engineer

But I went blank after every single one. So this time I am doing it differently — the hard way, the right way, the only way that actually works.

## The Rules

1. **Every line of code is written by me, from memory** — after reading/studying a concept, I close everything and write it myself
2. **No moving forward until the current concept is solid** — I can explain it, not just run it
3. **Every concept gets a small program** — not just notes, actual working code
4. **Consistency over speed** — slow and deep beats fast and shallow
